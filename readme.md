# Student Task Management System

A simple and responsive web-based task management application designed to help students organize and track their academic, personal, and project-related tasks.

## Project Overview

The Student Task Management System allows students to create, manage, search, update and track their tasks through a clean dashboard.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Filter tasks by status
- Search tasks
- Task categories
- Due dates
- Task statistics
- Local browser storage
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## DevOps Practices

The project is maintained using Git for source code management and GitHub for repository hosting.

The project also includes a basic GitHub Actions workflow for Continuous Integration.
